Instalacija CookieConsent

Odaberite način instalacije, postavite vlastitu politiku kolačića i provedite provjeru stvarnih opcionalnih usluga.

1. Web — lokalna instalacija

Preuzmite Standalone ZIP, prenesite JS i CSS na vlastitu web-stranicu te ih uključite prije opcionalnih skripti.

<link rel="stylesheet" href="/assets/brendigo-cookieconsent.css">
<script>
 window.BCC_SITE_CONFIG = {
  language: "hr",
  policyUrl: "/politika-kolacica",
  revision: "1"
 };
</script>
<script defer src="/assets/brendigo-cookieconsent.js"></script>

2. WordPress dodatak

Preuzmite brendigo-cookieconsent-wordpress.zip, instalirajte ga kroz Dodaci → Dodaj novi → Prenesi dodatak i otvorite Postavke → CookieConsent. Konfigurirajte izgled, jezike, kategorije, katalog usluga i politiku kolačića.

3. Vlastiti CDN

Za cookie.brendigo.com izrađuje se verzionirani CDN paket. Tek nakon stvarnog postavljanja DNS/TLS i datoteka moguće je koristiti sljedeći URL:

<script defer src="https://cookie.brendigo.com/v0.9.0/loader.js"></script>

4. Prije objave

  1. Napravite potpun popis stvarnih kolačića, skripti, piksela, iframeova i server-side događaja.
  2. Neobvezne resurse blokirajte prije valjane privole.
  3. Testirajte jednako jednostavno prihvaćanje i odbijanje te povlačenje privole.
  4. Uskladite politiku privatnosti, svrhe, rokove i pravnu osnovu s stvarnim ponašanjem stranice.
  5. Provjerite pristupačnost i stvarne mrežne zahtjeve.
